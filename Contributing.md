# Contributing to Bangladeshi Developers Community

---
1. Fork this repository.
2. Clone your forked repository to your local machine.
3. Create a new branch (i.e. `add/your-name`).
4. Add Your Information 
    1. Open `README.md` and scroll to your University section.
        - If it doesn’t exist, add a new heading:
            ```markdown
            ## University Name — Full Official Name
            ```
    2. Add your entry under your university in numbered order (1, 2, 3…)
    3. Follow the format 
    
        ```markdown
       ##  1.  Alamgir Hosain
        - **Email**: alamgir.ahosain@gmail.com  
        - **LinkedIn**: https://www.linkedin.com/in/alamgir-ahosain/
        - **GitHub**: https://github.com/alamgir-ahosain
        - **Portfolio / Personal Website**:  https://alamgir-ahosain.github.io/alamgir-book/
        - **Technologies**: Java,Spring Boot
        - **Short Description**: Final year CSE student passionate about Java and Spring Boot with a growing interest in DevOps and backend architecture. 
        - **Additional Links**: [Medium](https://medium.com/@alamgir.ahosain)
        <br><br>
        ```
5. Commit changes and push the new branch.
6. Open and submit a Pull Request.
